Bitget Grid Control

Private market monitoring, analytics and workflow automation.

Personal-use application.

Bitget Grid Control is an internal tool used by its owner to collect market data, run analytical calculations, maintain Google Sheets/Drive records and operate scheduled Google Apps Script workflows. It is not offered as a public service and does not provide public account registration.

Google account access

The application uses Google OAuth only to perform functions requested by the owner, including access to Google Drive files, Google Sheets, Apps Script project resources, scheduled script execution and external HTTP requests required by the workflow.

Google user data is used only to operate the application for the authenticated owner. It is not sold, used for advertising, or shared with unrelated third parties. Google user data is not sent to Bitget or other market-data providers.

Market analysis and automation outputs are informational tools. They do not guarantee investment performance or trading results. The owner remains responsible for all financial decisions.
